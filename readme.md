# Hotel Management System

Projet intégré : Développement Web Avancé & DevOps.

## Stack
React, Vite, Bootstrap 5, Node.js, Express, MySQL, Docker, Jenkins.

## Workflow Git
- `main` : branche stable (protégée)
- `dev` : branche d'intégration
- `feature/*` : une branche par fonctionnalité, fusionnée dans `dev` via Pull Request

## Convention de commits
Conventional Commits : `type(scope): description`
Types : feat, fix, docs, style, refactor, test, chore, build, ci
